## 目标

实现 SushiTile 的点击两次交换 + 拖动交换。

## 来源

- 设计：ADR-001-触控交互实现.md（完整方案）

## 验收标准

- [ ] `pointerInput { detectTapGestures }` + `detectDragGestures`
- [ ] 拖动阈值：< 30% 寿司宽度判定为点击
- [ ] 拖动到相邻位置触发交换
- [ ] 拖动中寿司跟随手指（半透明 alpha=0.7）
- [ ] 无效交换（无三连）弹回动画
- [ ] 长按 + 拖动边界处理（避免同时触发 tap 和 drag）

## 技术要点
