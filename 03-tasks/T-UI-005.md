## 目标

屏幕顶部显示倒计时 + 消除时显示 +5s 飘字动画。

## 来源

- 需求：FR-6.2（顶部显示）/ FR-6.3（最后 10s 红闪）/ FR-6.6 (+5s 飘字)
- 设计：ADR-004 / 02-arch-diagram.md §3.2

## 验收标准

- [x] `TimerDisplay(remainingSeconds, lastReward)` Composable
- [x] 倒计时大字号（48sp）
- [x] 最后 10s 数字变红 + 闪烁（500ms 切换，#E85D2F ↔ #FFB347）
- [x] 消除时显示 +5s 飘字（向上飘 + 渐隐，1.5s 后消失）
- [x] 倒计时 0 时显示 "时间到" 文字（灰色 #666666）

## 技术要点

- `animateColorAsState` 颜色过渡（300ms tween）
- `LaunchedEffect(remainingSeconds)` + `while` 循环驱动 500ms 闪烁
- `AnimatedVisibility` + `slideInVertically` / `slideOutVertically` 飘字
- `LaunchedEffect(lastRewardSeconds)` 1.5s 后自动隐藏飘字
