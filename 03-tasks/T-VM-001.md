## 关键设计决策

1. **GamePhase 从 sealed class 改为 enum class**：原 Models.kt 中的
   `sealed class GamePhase { IDLE; ANIMATING; GAME_OVER }` 不支持 `PAUSED`
   状态，无法表达活动生命周期的暂停/恢复。改为 `enum class GamePhase { IDLE,
   PLAYING, PAUSED, GAME_OVER }`，并从 `Models.kt` 移到 `engine/GameState.kt`
   （与 `GameState` 共置）。`PLAYING` 替代原 `IDLE` 的"可玩"语义；真正的
   `IDLE` 保留为"未启动"占位状态。
2. **VM 构造时自动 startGame()**：`init { startGame() }` 在 VM 创建后立即
   启动计时器（与设计文档 §2.1 一致）。MVP 暂不提供"开始游戏"按钮。
3. **swapProcessing 单线程 var**：`viewModelScope` 默认 `Dispatchers.Main.immediate`，
   所以普通 `var` 已足够（无需 `AtomicBoolean`）。在 `onSwapAttempt` 入口
   置 `true`、所有 return 路径前 `false`。
4. **无效交换回弹 = 150ms 临时显示 + 还原**：`isRollback = true` + `board = swappedBoard`
   → `delay(150)` → `board = original` + `isRollback = false`。UI 监听
   `isRollback` 翻转播放抖动/回弹动画。
5. **TimerEngine.rewardOnMatch 用 cascadeResult.cascades.flatten()**：一次奖励
   +5s（capped 90），不分 match 个数，与 FR-6.5 / TimerEngine 契约一致。
