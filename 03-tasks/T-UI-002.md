# T-UI-002: GameCanvas + SushiPainter（Canvas 绘制）

**状态：** ✅ done
**优先级：** P0
**预估：** 8h
**Owner：** main agent
**依赖：** T-CORE-001, T-RES-001, T-UI-001
**可并行：** -

## 目标

用 Compose Canvas 绘制 7×7 棋盘 + 寿司图片。

## 来源

- 设计：ADR-001（CanvasComposable 渲染）
- 设计：02-arch-diagram.md Level 2（GameCanvas）

## 验收标准

- [ ] `GameCanvas(board, onTileAction)` CanvasComposable
- [ ] 绘制 7×7 网格（边框 + 背景）
- [ ] 每个格子绘制对应寿司 PNG
- [ ] 寿司大小自适应屏幕
- [ ] 选中状态高亮（边框变红 + 缩放 1.15x）
- [ ] 锁定状态半透明
- [ ] 棋盘整体在屏幕居中，顶部/底部留给分数/倒计时

## 技术要点

- 用 `Canvas { drawImage(...) }` 或 `Image(painter, ...)`
- `drawScope.drawImage()` API
- 7×7 网格用 `forEach` 循环
- 寿司 PNG 加载：`ImageBitmap.imageResource(R.drawable.sushi_1)`
